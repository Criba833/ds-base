7 · Icons

Only the core contract .ds-icon (box 1em × 1em, inherits color, no stroke/fill assumptions). Four cards use the optional Bootstrap Icons adapter — fonts served from adapters/icons/bootstrap/assets/, not copied. Every glyph inherits its surrounding text color.
